# 応用情報 索引検索

キタミ式イラストIT塾 応用情報技術者 令和08年版と、令和08年 応用情報技術者 合格教本の索引語から、掲載ページを検索します。学習管理アプリとは独立した静的ツールです。画像、サーバー、DB、外部サービスは使いません。

## 公開サイト

[応用情報 索引検索を開く](https://akanegit.github.io/ap-index-search-kitami-gokaku/)

スマートフォン・PCのブラウザから利用できます。ログインは不要です。

## 使い方

`index.html` をダブルクリックしてください。教本を選び、言葉を入力すると部分一致で検索します。英字の大小、全角・半角、空白や一部記号の違いを吸収します。GitHub Pagesにこのフォルダの中身を置いても動作します。

検索結果の `p.123` は**本文の掲載ページ**です。「要確認 · 索引 p.940」の番号は、その項目を読み取った**索引ページ**です。`123,125` や `123-125` は索引の表記を残しています。

## データの直し方

- `data/kitami/index-935.json` から `index-951.json` は、キタミ式の**索引ページ別**の用語です。`data/gokaku/index-786.json` などは合格教本のデータです。
- 各 `entries` の `word`（索引語）と `pages`（本文ページ）を直してください。確認できた項目は `needsReview` を `false` にできます。行の特定には `indexPage`、`column`（0=左、1=右）、`row` を使えます。
- 編集後、このフォルダで `python3 build.py` を実行すると、ダブルクリック用の `index-data.js` と `要確認一覧.csv` が更新されます。Python 3だけで実行できます。
- `要確認一覧.csv` はキタミ式で読みに不安があった項目の一覧です。元画像はZIPに含みません。修正したい行があれば、索引ページと用語・掲載ページを伝えてください。

## 読み取りの精度

キタミ式は索引 p.935〜951 の画像から自動で読み取りました。**すべての項目が未校正**で、`needsReview` が `false` でも正しさを保証しません。読めない文字、抜けた行、別の行に紐付いたページ、途中で切れた複数ページ表記があり得ます。「要確認」は機械的に見つけた疑わしい項目の印です。

合格教本は以前作成した検索データを引き継ぎ、画像を除きました。`verified-extra.json` は以前確認した項目のうち索引ページを特定できなかったものです。合格教本の画像読取候補も未校正です。

`index-data.js` はJSONから生成した検索用コピーです。JSONの修正は `build.py` の実行まで画面に反映されません。

## GitHub Pagesの更新

このフォルダがGitリポジトリのルートです。GitHub Pagesは `main` ブランチの `/ (root)` を公開します。`.nojekyll` により、HTMLとJavaScriptをそのまま配信します。

索引データを編集した場合は、Python 3が使える環境で次を実行してください。

```sh
python build.py
```

変更を確認してから、GitHubへ送信します。

```sh
git status
git add .
git commit -m "Update index search"
git push
```

送信後、数分で公開サイトに反映されます。公開状況はリポジトリの **Actions** または **Settings → Pages** で確認できます。
